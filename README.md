# Online Feedback Collector with Admin Dashboard

## Description
Online Feedback Collector is a web application built using Flask and SQLite.  
Users can submit feedback through a form, and the admin can log in to a dashboard to view, analyze, and manage the feedback.

## Features
- Submit feedback (Name, Email, Rating, Comments)
- Star rating system
- Secure admin login
- Admin dashboard with feedback table
- Total feedback and average rating
- Bar chart and pie chart visualization
- Delete feedback entries
- Export feedback data to CSV
- REST API endpoint for feedback data

## Technologies Used
Frontend:
- HTML
- CSS
- JavaScript
- Chart.js
- Font Awesome

Backend:
- Python
- Flask

Database:
- SQLite

## How to Run the Project

1. Install Flask

pip install flask

2. Run the application

python app.py

3. Open in browser

http://127.0.0.1:5000
